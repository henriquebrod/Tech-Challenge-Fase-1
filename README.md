# Tech Challenge - Fase 1

Este repositório contém a entrega da Fase 1 do curso de Ciência de Dados.

## 📁 Estrutura do Repositório

- `data/`: Arquivos de dados utilizados.
- `notebooks/`: Análises exploratórias e notebooks Jupyter.
- `src/`: Scripts Python e funções auxiliares.

## 🚀 Como executar

1. Clone o repositório.
2. Abra os notebooks na pasta `notebooks/` para visualizar as análises.
